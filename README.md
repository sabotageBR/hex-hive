# Combloom

Puzzle 3D de pilhas hexagonais numa colmeia, com um jardim que floresce a cada fase. HTML + ES modules sem bundler,
three.js r187 vendorizado, sons sintetizados, arte do Grok. Builds para Poki, CrazyGames (Full e Basic Launch),
californiagames.io e Y8 pelo kit multiportal do estúdio. Na 1.1.0 a colmeia gira (gestos, botões, Q/E) e as peças
ganharam acabamento novo (chanfro arredondado, brilho, sombras de contato e um símbolo por cor).

- Design: `docs/GDD.md` (loop, primeiros 3 minutos, novidades, jardim, bíblia de arte).
- Arte: `docs/autoria.md` (prompts e escolhas).
- Como rodar, testar e empacotar: `CLAUDE.md`.
